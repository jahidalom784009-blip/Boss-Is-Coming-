# Boss Is Coming! — HTML5 Comedy Game

A colorful, mobile-friendly office comedy game with five levels. Move left/right, hold LOOK BUSY to earn productivity points, use SNEAK to slow the boss, avoid getting caught, toggle sound, pause, and restart. Score and best score are stored locally.

## GitHub Pages setup
1. Create a public repository, e.g. `boss-is-coming`.
2. Extract this ZIP and upload all files in this folder to the repository root.
3. Go to Settings → Pages.
4. Choose `Deploy from a branch`, branch `main`, folder `/(root)`, then Save.
5. Wait for deployment and open the Pages URL shown there.
6. Android Chrome: menu ⋮ → Install app / Add to Home screen.

## Controls
- Mobile: ◀ / ▶ move, LOOK BUSY button to earn work points, SNEAK to slow the boss.
- Desktop: A/D or arrow keys to move, W/Space/Up to work, Shift to sneak, Esc to pause.

The game is a standalone original implementation; no external libraries or server required.
